## 🚀 High-Impact Technical Projects
*Focus: AI Integration, Cloud Architecture, and End-to-End Engineering.*

### 1. LabOps.AI — Biological Process Intelligence
**Overview:** A pre-seed stage platform for biomanufacturing facilities (cell/gene therapy), providing a "connective intelligence layer" for manufacturing legibility and compliance.
- **Key Features:**
    - **Scientific Literature RAG:** Automated pipeline (RSS → PDF → Markdown → Chunker → Embedder) that makes biomanufacturing research queryable in natural language.
    - **Knowledge Management:** Integrated Obsidian vault seeded directly from RAG-synthesized literature.
- **Tech Stack:** Python 3.13, Gemini 1.5 Flash, ChromaDB (Vector Store), SQLite, `sentence-transformers`, PyMuPDF.
- **Resume Impact:** AI/LLM Engineering, Biomanufacturing Domain Expertise, Full-stack Data Pipelines.

### 2. BLK PHX LABS — Intelligence Engine (`AI_BRIEFING`)
**Overview:** An autonomous biotech intelligence pipeline that scrapes Google Alerts and publishes a spoken audio/video briefing to a cloud-hosted dashboard.
- **Key Features:**
    - **Three-Pass RAG:** Sequential Extract → Analyze → Narrate engine for high-fidelity synthesis.
    - **Cloud Automation:** Fully serverless architecture triggered daily at 6 AM.
- **Tech Stack:** Google Cloud (Functions, Run, Storage, TTS), Google Apps Script, Gemini API, MoviePy, Python.
- **Resume Impact:** Cloud-Native Architecture (GCP), Automated Media Synthesis, AI Agents.

### 3. BLKPHXLABS — Dissertation RAG Pipeline
**Overview:** A specialized tool for converting complex PDF dissertations into structured Markdown and interactive chat interfaces.
- **Key Features:**
    - Automated heading detection from PDF font sizes.
    - Streamlit-based UI for retrieval-augmented conversation with academic documents.
- **Tech Stack:** Python, Streamlit, PyMuPDF, ChromaDB, Gemini.
- **Resume Impact:** NLP, Complex Document Parsing, Rapid Prototyping.
